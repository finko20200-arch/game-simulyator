## Структура проекта

```
/workspace
├── index.html          # Главный HTML
├── css/
│   └── style.css       # Стили
├── js/
│   ├── config.js       # Конфигурация
│   ├── utils.js        # Утилиты
│   ├── story.js        # Сюжет
│   ├── game.js         # Движок
│   ├── main.js         # Точка входа
│   └── test.js         # Тесты
├── assets/
│   ├── bg/             # Фоны
│   └── char/           # Спрайты

```

## Запуск

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
python3 -m http.server 8000
# или
npx serve .
```

## Управление

- **Клик / Пробел** — продолжить диалог
- **Esc** — открыть меню
- **Стрелки** — выбор вариантов

## Конфигурация

Измените `js/config.js` для настройки:
- Баланс игры (аффинность, осколки)
- Скорость текста
- Пути к ассетам
